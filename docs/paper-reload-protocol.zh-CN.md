# 多平台纸面重载协议

本协议适用于所有策略、平台和插件组合，尤其是含杠杆的策略。它不替代回测，也不授予实盘权限。

1. **证据完成**：生成可复现的历史回测、交易/持仓序列、成本假设、压力情景和人工验收；证据包须能通过 promotion 验证。
2. **发布身份**：对已提交的策略 revision、配置、风险规则、证据和完整插件包运行 `assess_strategy_release.py`。只有 `ready: true` 才能由受控发布流程生成 manifest。
3. **全目标预装**：将同一个 release identity 加载到目标平台的纸面运行时；每个平台必须回传匹配的 `runtime_release_receipt`。缺失或 digest 不一致即停止。
4. **纸面执行校验**：先验证只读状态、撤单、未知订单结果对账、HALTED/REDUCING 边界和风险增加拦截；任何异常只允许降风险或暂停。
5. **观察期**：跨越约定交易日和至少一个高波动场景后，比较目标、成交回执、仓位和风险诊断。出现漂移时回到第 1 步，不自动放宽参数或增加风险。
6. **单独授权**：纸面观察通过不等于实盘授权。实盘启用、加杠杆或修改止损仍需要新的证据、manifest 和明确人工批准。

SOXL 当前在第 1 步阻断：仓库内不存在可验证的 promotion 证据包，因而没有 manifest，也不能进入任一平台的重载、ACTIVE 或实盘步骤。
