# 设计说明：凯利外层的证券级净交易账本（RS-07 (c)）

> 仅限研究。本文只是设计，不改代码、不改生产。

## 1. 现状（审计 (c) 已核实为真）

`fractional_kelly_walk_forward` 和 `portfolio_kelly_walk_forward` 的外层把每条策略收益流当成一个**虚拟资产**：

- 每个交易日开盘前再平衡到目标仓位 `f`（组合版是权重 `w`），剩下的放现金。
- 交易额 = 外层调仓 `|f − 漂移后仓位|` + `f × 内层换手`，费用按交易额乘以 bps。
- 外层现金腿（BOXX 收益序列）**不收费**；但内层核心路径里买卖 BOXX 要收费。
- 外层和内层对同一只证券的买卖**不互相抵消**。例如外层减 SOXL、内层同时加 SOXL，两笔都收费。

后果：费用可能高估（没有抵消），也可能低估（外层现金腿免费、每日再平衡在现实里会产生零碎交易），方向不确定。所以目前的成本档只能算近似值。结果里的 `cost_model_disclosure` 字段已注明这一点。

## 2. 目标

在**证券层面**计算每日净交易：先按持仓合并所有层的目标，再与前一日漂移后的真实持仓比较，按证券算一次交易额。费用和换手都以这笔净交易为准。

## 3. 设计

1. **持仓表**：每个交易日 t 记录 `holdings[t][symbol]`（占净值的比例），覆盖 SOXL、SOXX、TQQQ、QQQM、BOXX 和现金。
2. **合成目标**：`target[t][s] = Σ_k w_k(t) · inner_weight_k(t)[s]`。k 是策略流（单策略时只有一个，`w = f`）。外层现金和内层 BOXX 合并成同一个 BOXX 仓位，另有一个不计息、不收费的真正现金项（仅用于结算缓冲，默认 0）。
3. **净交易**：`trade[t][s] = target[t][s] − drift(holdings[t−1])[s]`，`turnover[t] = Σ_s |trade[t][s]|`，BOXX 也计入（与内层口径一致）。
4. **费用**：`cost[t] = Σ_s |trade[t][s]| · bps_s · 档位`，可以按证券设不同 bps（如 BOXX 价差更小），需事先预注册。
5. **再平衡规则（预注册参数）**：保留"每日到目标"作为上界；另加偏离带（比如任一证券偏离超过 x% 才调仓）作为更贴近实盘的变体。改变规则就算新试验，要登记到账本。
6. **输入要求**：核心生成器需要输出每日内层**证券**权重（`CorePath.weights` 已有），不再只输出汇总换手。
7. **校验**：(a) 单策略、`f = 1`、无外层调仓时，净交易账本应与内层换手完全一致；(b) 外层与内层交易方向相反时，净额小于两者之和；(c) 现金和 BOXX 合并后总权重恒为 1。
8. **输出**：在 `backtest_report.v1` 的 `cost_model` 里把 model_id 改为 `security_level_net_trades`，并保留旧口径作为诊断，便于对比。

## 4. 不在本次范围

整股、结算周期（T+1）、最小交易额、实盘成交价滑点，这些要等实盘成交导出（见一致性清单）后再校准。
