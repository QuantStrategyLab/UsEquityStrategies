# 盘中多事件状态与初始化、迁移离线合同

本包仅消费人工账户、人工政策与人工来源证明，复用原风险计算和 QPK `LocalObjectStore` 的读取与 create-only 写入。没有连接真实账户、交易日历、云存储、配置消费者或下单入口，输出始终不授权执行、不启用配置、不解除熔断。

## 顺序与保护

`portfolio_event_journal.py` 的 `qsl.portfolio-event-journal.v1` 独立于原按日状态链。记录包含固定身份、事件 ID、严格递增的序号、UTC 观察时间、有效日、完整输入摘要、状态摘要和前序摘要。同一天可以产生多条记录；原 `StrategyRiskStateStore` 仍每天只允许一条，未放宽或伪造日期。

- 观察时间不能倒退；有效日沿用现有研究接口的 UTC 日期口径，不代表原生券商交易日或跨日历接入已通过。
- 事件 ID 必须是明确提供的安全 ASCII 标识，最长 128 字符；同 ID 改内容是冲突，同一冻结请求重放只恢复状态，不重新返回配置草稿。
- 同一日的 `session_start_nav` 保留不变。`session_net_external_flow` 是调用方明确给出的当日累计流量，每次重新计算，不把它逐次累加。真实资金流账的完整性和来源仍须实际平台证明。
- 已有 OPEN、原触发点、净值高水位与持仓周期保护跨事件和重启保留。恢复资格通过不会清除 OPEN；新政策也不能自动放松已锁定保护。
- 新状态不能晚于调用方提供的 checkpoint 观察时间。时间或来源不相容时写前拒绝，不自动把 checkpoint 时间改成当前时间。

目录按风险作用域和完整身份分隔；同一作用域只允许一个 create-only 初始起点。更换政策或组合身份不能再次初始化一个 CLOSED 根来绕过原状态。后继按前序摘要寻址，用原存储的独占创建解决竞争写入。没有可变的 latest 文件、覆盖写或另一套数据库。

## 接口与证据

| 接口 | 输入与终态 |
| --- | --- |
| `initialize_portfolio_event_state` | 显式初始状态、日初基准、完整身份、状态摘要、来源引用/版本及有效时间。缺失不默认为 CLOSED；重复初始化不能重置已使用的链。只返回状态，不生成配置。 |
| `read_portfolio_event_state` | 新鲜、同账户/作用域/币种的 checkpoint 与精确预期头部摘要；核完整记录链、保护连续性和初始/迁移来源。空目录、坏文件、缺失来源或摘要不匹配均禁止新增风险。 |
| `persist_portfolio_intraday_preview` | 读取已验证状态，调用原智能/高级预览、RiskEngine、费用/数量与风险约束，写一次并完整读回。已确认的新 OPEN 可保存，即使减仓配置仍有缺口；无合格草稿就不暴露草稿。 |
| `migrate_portfolio_event_state` | 人工迁移证明绑定旧/新身份、旧头部、状态摘要和来源；先提交旧链 `MIGRATE_OUT` 封存，再提交新链 `MIGRATE_IN`。原 OPEN、高水位、触发点、周期保护和日初基准完整复制。 |
| `prepare_daily_state_import` | 对原按日存储只读核对并交出状态候选；不写新根、不停旧消费者。缺少旧写者停写交接与盘中日初基准来源，明确返回准备态及缺口。 |

初始化与迁移证明必须在其 `available_at` 以及本次接收时有效。尚未生效的旧证明须由来源方重新出具，本接口不代改时间或制造批准。历史读回按原可用时点核验，不将旧证明重新发行成今天的权限。

这里的来源证明是注入的、版本化的人工合同。摘要能证明内容连续性，不能证明发行方真实可信。没有实现真实 checkpoint、初始化或迁移权限的发行服务；`authority_classification` 明确保持人工来源，不能把 `readback_verified` 当成资金或生产授权。

## 迁移中断与失败

迁移使用两次不可变写入，不声称跨对象事务。旧链封存成功后，旧身份不能再产生事件或草稿。若新根未确认，旧链继续保持封存；相同冻结迁移可以在读回确认原封存后接续新根，不能生成另一条旧链转换或改换目标。

`source_retired` 为 `null` 表示旧链写入结果尚未确认，不能解释为旧链仍可运行。只有完整读回确认才给出 `true`。初始化和迁移接口始终不返回配置草稿；迁入后仍需下一条新鲜事件按新政策重新验证。

原本地 provider 在独占创建后写入、flush 和 fsync。进程中断可能留下不完整 JSON；本包保留坏文件并阻断，不自动删除、覆盖或重试。丢失回执时只读核对已提交内容。坏存储恢复、断电耐久、备份、跨机器运行和真实来源仍不在此验证范围。

路径只允许显式批准的人工离线目录，拒绝云 URI、目录外路径及作用域内符号链接。调用方仍须控制该目录；这些检查不声称防住恶意文件系统竞态。其他账户作用域的材料不作为本作用域的初始化依据。

## 验证与剩余条件

新测试覆盖同日多事件、次日基准、重放/冲突、竞争写、来源/时间、起点唯一性、坏文件与保护回退。独立进程演练覆盖 CLOSED→OPEN、多次 OPEN、重启只读恢复、提交前/后中断、部分写入和旧链封存后的迁移接续。CI 强制收集这些用例并拒绝跳过，原按日测试和运行导入边界继续检查。

仍需真实来源支持的项目是：有效账户预算与风险阈值、真实 checkpoint/初始化/迁移发行方、原按日消费者的停写交接与日初基准、实际持久存储及资金流账，以及真实配置消费者的预览/生效读回。本包没有新增真实回测、选择参数/窗口或提供收益提升证据。

后续[离线备份恢复与草稿读回](offline-state-recovery-and-drafts.zh-CN.md)已补齐完整链快照、空目录恢复和配置草稿的只读消费者预检；真实停写、实际存储灾备和配置生效仍按上述条件独立验收。
