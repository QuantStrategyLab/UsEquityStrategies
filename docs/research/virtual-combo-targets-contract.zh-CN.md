# 虚拟组合目标 P2 研究契约

`virtual_combo_targets` 是组合仓位管理的最小 P2 研究组件。它只把至少两份
**冻结的单策略虚拟目标**按冻结的策略预算合成为一个虚拟组合目标，再应用明确的
组合风险预算。它不读取账户、凭证或市场数据，不写入任何状态，不调度任务，不
下单，也不授予 P4 paper、P5 shadow 或 P6 live 权限。

## 输入边界

每个单策略输入都必须是 `FrozenStrategyVirtualTarget`：

- `strategy_id`、其 P1 输入摘要及目标本身的自校验 SHA-256；
- long-only、总和为 1 的虚拟目标权重；
- 按 `strategy_id` 排序，至少两条策略。

组合策略预算也必须总和为 1，并且每条策略都要有冻结的最大预算。组合策略不会
接收单策略的收益、夏普、评分、晋级建议或任何 P4--P6 授权字段；因此它的结果
**不是组合绩效证据**，更不能把单策略回测结果误写成组合回测结果。

策略与资产的限制分为以下独立层次：

- 策略层：单策略最大预算；
- 组合层：非现金名义风险权重（gross）上限；
- 标的/经济底层层：复用 `portfolio_risk_budget` 的单标的、有效敞口和底层重叠
  上限；
- 相关性层：预先声明的、至少含两个非现金标的的相关风险组及其有效敞口上限。

相关风险组是确定性的政策输入，例如把 TQQQ 与 QQQM 放入 Nasdaq 风险组；它不
估计相关系数，也不宣称拥有相关性的历史统计证据。未来 P1/P3 可用冻结的历史
数据单独评估该政策，但该证据链不属于本模块。

## 输出与 fail-closed

输出 schema 为 `qsl.us-equity-virtual-combo-target.v1`，只可能是：

- `APPROVE`：虚拟组合目标在全部预算内；
- `REDUCE`：对全部非现金目标进行同一比例缩减，移除部分转至政策声明的现金
  资产；
- `PARKED`：输入不完整、摘要失配、政策变更、标的未知、策略超预算或再平衡
  基线缺失。

每个结果都带有 `research_only: true`、`execution_authorized: false` 与
`evidence_scope: VIRTUAL_TARGET_CONSTRUCTION_ONLY`。摘要仅包含 gross、策略预算、
有效敞口、经济底层/相关组敞口和虚拟换手；不包含账户、订单或机密信息。

如果政策启用 `max_one_way_risk_turnover`，调用方必须同时提供一个具有自校验摘要的
`FrozenVirtualComboBaseline`。该基线只能是此前的虚拟组合目标，不能替换为真实
账户仓位；缺失时立即 `PARKED`。

## 后续接线

本切片只完成 P2 的目标构建。它仍缺少：可复核的组合 P1 历史输入、组合 P3 回放
和独立绩效证据、受限 scheduler 工件，以及后续 P4/P5 适配器。只有 P1/P3 形成
独立组合证据后，才可以把这个虚拟目标用于 paper 或 shadow 的比较；它本身永远
不是执行指令。
