# 组合风险预算研究契约

`portfolio_risk_budget` 是组合候选在 P2/P3 使用的纯计算组件。它不会读取
账户、调用券商、下单、写数据库、调度任务或授予 P4--P6 权限。

它接收一份已经由策略生成的 long-only 目标权重，以及每个资产明确的：

- 有效敞口倍数；
- 经济底层（例如 TQQQ 与 QQQM 都映射到 `NASDAQ100`）；
- 现金/防守资产标记；
- 组合候选冻结的有效敞口、单标的、底层重叠与单向风险换手上限。

输出只能是：

- `APPROVE`：目标未超过研究预算；
- `REDUCE`：按同一比例降低全部非现金风险资产，并把移除部分转至声明的
  现金资产；
- `PARKED`：输入、资产映射或预算不完整/不合法。
  推荐权重形成后，任一显式单标的上限（含现金）被突破也是 `PARKED`，且不会反向提高风险资产去满足该上限。

所有结果的 `execution_authorized` 均为 `false`。`REDUCE` 只是用于历史
回放和未来 shadow 比较的建议目标，不是订单、资金分配或自动化许可。

## 当前范围

这解决的是组合层此前缺少的统一检查：单策略内部可以有趋势防守或单资产
风控，但它们不会自动识别 TQQQ 与 QQQM 的 Nasdaq 重叠，也不会统一限制
TQQQ/SOXL 的合计杠杆风险或组合的风险买入换手。

首个消费者应是新的组合 P1/P2/P3 研究链：使用可复核历史价格、时点
Russell 成分、交易日历和预先声明的成本模型重建组合结果。旧的派生收益
回放仍仅为探索性参考，不能把其数值直接写入本模块的政策或拿来晋级。

## 统一组合分配与风控分析

策略评价沿用 QPK 的
[策略晋级与风险标准](https://github.com/QuantStrategyLab/QuantPlatformKit/blob/main/docs/strategy_promotion_risk_standard.zh-CN.md)：
共同声明样本单位、净/毛收益、币种、成本/现金流、rf、时间与年化、不可计算
状态，并分别标记报告、排序和否决项；类别门槛在读取留出结果前由候选冻结。
采用时核对消费者实际 pin，不能把 QPK main 文档等同于已安装实现。

Markowitz、fractional Kelly 与经验 log-growth 放在同一个组合分析范围，
但保留独立的目标、输入假设、候选身份与输出。它们不合成单策略评分，也不
因属于同一分析范围就自动串接、叠乘或提高仓位。

| 方法或组件 | 当前可核对的实现与边界 |
| --- | --- |
| 固定权重协方差诊断 | 本文下节的 `attribute_fixed_weight_return_risk` 已计算样本方差、相关和贡献；权重由 caller 给定，函数没有求解 Markowitz 最优权重 |
| Markowitz 均值—方差 | 在本组合研究路径中尚未实现或验收 μ/Σ 到最优权重的求解与稳健估计；不能用已有协方差诊断宣称这一步已完成 |
| fractional Kelly | QPK [Kelly 契约](https://github.com/QuantStrategyLab/QuantPlatformKit/blob/main/docs/kelly_contract_v2.zh-CN.md) 已区分二元风险份额与资金暴露，并限制样本、回撤与预算；这是 research-only helper，不等于相关资产联合优化或交易消费者已启用 |
| 经验 log-growth | [R8](first_compounding_20260925/r8_joint_allocation_status.md) 已用配对历史情景的可执行费用后账户终值选择有限 B0–B3 动作；这是一步经验增长目标，历史结果为 development，后续 promotion adapter 仅 synthetic 验收，不证明长期最优或未触碰 OOS |

后续方法比较复用既有组合账本和候选证据，不另建共账户 allocator。先冻结
共同日期、可知截止、币种、现金收益、资金流/起点状态、费用及执行合同，
以及各方法可用的估计窗口、输入和约束。均值/协方差的估计方法、样本量、
稳定性与不确定性处理明确记录；Kelly 的收益样本和亏损份额单位不能套用为
组合资金权重，fractional 缩放也不能被重新归一化为满仓。

独立 OOS 和成本压力比较使用相同可执行账户约束，同时报告净增长、波动/
尾部共亏、回撤金额与恢复、换手/费用和资金短缺。单策略指标不得相加冒充
组合；单日情景评分不得冒充实现收益。已有负结果、失败试验及尚未计算的
不确定性诊断保留，未完成真实验收的方法不升级为默认。

现有预算组件只收紧已经提出的目标，移除部分留在声明的现金资产中。
有效敞口、单标的/底层重叠、流动性、回撤/熔断及最终账户风控继续独立约束；
Kelly 的增长目标不保证回撤，估计相关较低也不保证危机分散。任何新方法
接入都不因本文而改变既有数值上限、平台 sizing 或执行权限；本纯函数存在
不证明各平台已经实现或采用上述全部风险控制。

本节归入已有 `STRAT-04`，复用 `STRAT-02` 的评价口径及 `STRAT-05`
的风险边界。本次只对齐文档，不修改 schema、算法、冻结政策、权重或旧证据，
也不将方法讨论标成实际采用。

## 固定权重同窗样本诊断

`attribute_fixed_weight_return_risk` 只描述一套已经明确的资产目标权重，
在同一估值币种、同一组严格对齐的日简单收益上的样本统计。它不是回测，
不生成假定免费再平衡的收益曲线，也不是预测或推荐仓位。杠杆资产使用
调用方给出的收益，不再乘有效敞口倍数；上面的静态敞口约束仍单独判断。

输入是每个资产带日期的完整序列。权重键必须与收益键一致，有限且非负，
总和为 1（容差 `1e-12`）。共同日期必须逐项相同、严格递增，且不晚于
明确的 `as_of`。样本数下限由调用方给出，并且至少为 2。缺列、错日期、
非有限值、布尔值或样本不足都返回 `UNCOMPUTABLE`，不给统计数字。实现
不取日期交集、不把缺收益填成 0、不年化、不剔除极端值。名为现金的资产
也必须自带收益序列，不能按名称当成零收益。

协方差使用除以 `n-1` 的样本协方差。组合方差是 `w^T Σ w`，资产 `i` 的
方差贡献是 `w_i (Σ w)_i`，各项贡献之和等于组合方差。负贡献保留。
同时给出日波动（组合方差的平方根，单位是日简单收益，不年化）、贡献占
组合方差的比例，以及 Pearson 样本相关。相关用两条标准差相乘，不先把两个
方差相乘，以免大方差溢出或小方差下溢成 0。组合方差为 0 时贡献占比为
`null`；任一资产方差为 0 时，涉及该资产的相关为 `null`。不产生
NaN 或 inf。有限但在求和、转换或乘积中溢出的输入返回 `UNCOMPUTABLE`，
不给统计数字。统计能够算出只表示描述性诊断，`research_qualified`、
`execution_authorized` 和 `promotion_authorized` 仍为 false，也不补齐
晋级标准要求的风险证据包。

该诊断只由上述纯函数提供。它不写入 `aggregate_combo_evidence` 的结果，
也不进入成分聚合的 `evidence_digest`。

`extract_adjusted_close_simple_returns` 只从已暂存的 v2 数据集路径抽取资产
收益。它先调用现有 `load_price_snapshot_v2`，并要求 `object_identity.json`
或显式身份文件与 manifest generation 一致。这个文件核对不能证明对象确实
来自云端。只接受 `price_field=adjusted_close` 且 `adjustment=all`。每个
标的的收益是后一个复权收盘价除以前一个再减 1，从第二个价格日起算，并保留
第一个价格日。日期沿用快照里已经对齐的序列，不取交集、不补 0、不年化、
不乘杠杆，也不制造现金收益。来源沿用 loader 生成的 `input_digest`。
manifest 没有货币字段，因此这里不填写也不默认 USD。货币、现金收益和组合
权重仍未绑定。这不是策略净值收益、TWR/MWR、OOS，也不是可执行投资证据。
